# My Project Description

A simple and interactive **BMI (Body Mass Index)** Calculator built using HTML, CSS, and JavaScript.

## About the Project

This project calculates a person's Body Mass Index (BMI) based on their height and weight. It also displays a BMI category to help users understand their result.

## Features

- Calculate BMI using height (in centimeters) and weight (in kilograms).
- Validate user inputs to prevent invalid calculations.
- Display BMI results up to two decimal places.
- Show BMI categories: Underweight, Normal, Overweight, and Obese.
- Simple and user-friendly interface.

## How to Run the Project
- Clone or download this repository.
- Open the project folder in VS Code.
-Open index.html using the Live Server extension.
- Enter your height in centimeters and weight in kilograms.
- Click the Calculate button to see your BMI result.

## BMI Categories

| BMI Range | Category |
|---|---|
| Below 18.6 | Underweight |
| 18.6–24.89 | Normal |
| 24.9–29.89 | Overweight |
| 29.9 and above | Obese |
