# 🎯 Number Guessing Game

A simple and interactive **Number Guessing Game** built using **HTML, CSS, and JavaScript**.

The computer randomly generates a number between **1 and 100**, and the player has **10 attempts** to guess the correct number.

## 🎮 How the Game Works

1. The computer generates a random number between **1 and 100**.
2. Enter your guess in the input field.
3. Click **Submit Guess**.
4. The game tells you whether your guess is:

   * 🔽 Too low
   * 🔼 Too high
   * 🎉 Correct
5. Your previous guesses are displayed.
6. You have a maximum of **10 attempts**.
7. Once the game ends, you can click **Start New Game** to play again.

## ✨ Features

* Random number generation between 1 and 100
* Maximum of 10 attempts
* Displays previous guesses
* Shows remaining attempts
* Gives hints when the guess is too high or too low
* Validates user input
* Disables the input after the game ends
* Allows the player to start a new game
* Displays the number of attempts when the player wins
